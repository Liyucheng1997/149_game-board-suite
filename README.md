# 棋盘游戏综合

一个网页版棋盘游戏合集，包含国际象棋、中国象棋、五子棋、围棋和军师旅团营（标准军棋与翻棋快局）。

## 功能

- 五种棋类一键切换
- 电脑模式和本地双人模式
- 轻松、均衡、困难三档难度
- 响应式界面，支持桌面和移动端
- 国际象棋使用 `chess.js` 规则引擎
- 内置中国象棋、五子棋和 9 路围棋规则逻辑
- 标准军棋（默认）：12×5 完整棋盘、每方 25 子、10 个行营、4 个大本营，显示公路、铁路与中央三条通道
- 标准版采用双方明棋、自动合法布阵；军旗放在大本营、地雷限后两排、炸弹不在前排、行营开局为空；新局重新布阵
- 公路走一步，沿行营斜线也可走；铁路上普通棋子直行不限距离，工兵可以转弯，均不可越子；行营内免受攻击，大本营只进不出
- 翻棋快局：6×6 棋盘，每方 18 子，红方先手；每手翻一枚暗棋或将己方明棋上下左右移动一格
- 军棋等级：司令 > 军长 > 师长 > 旅长 > 团长 > 营长 > 连长 > 排长 > 工兵；同级同归于尽，小攻大则阵亡
- 工兵排雷、炸弹同归于尽，地雷与军旗不可移动；任何可移动棋子夺旗或使对方无棋可走即胜，连续 80 手未翻棋或吃子判和
- 翻棋快局无铁路、行营；两种军棋均支持电脑和本地双人。电脑不会读取暗棋身份，轻松随机、均衡侧重吃子、困难兼顾下一手威胁

标准版棋子与地形走法参考[军棋玩法指南](https://www.junqi.app/zh/rules)。本项目采用普通棋子撞雷后地雷保留、炸弹可夺旗、连续 80 手未吃子判和的约定；翻棋快局翻棋会重置和棋计数。规则说明也可在游戏右侧展开查看。
